# React starter (GitHub Pages)

A one-page site in the RedScope style: `brand/css/zone.css` (palette,
terminal-like font, light and dark), the eye, favicon and app icons from
`public/brand/`. Published to GitHub Pages by `.github/workflows/pages.yml`
on pushes to `master`.

```sh
npm ci
npm run dev      # local
npm run build    # dist/
```

Take it from a built pack (`starters/react/`): the repository's source of the
starter has no `public/brand/`.

Status: builds (`task check` of rs-tech-brandstyle); not yet published.
