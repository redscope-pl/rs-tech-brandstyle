# Blogger theme

For `blog.redscope.online` (Blogger's own address
`redscopetech.blogspot.com`): articles and news in one readable column,
light and dark from the visitor's scheme, the eye in the header (inline,
nothing to host), labels in crimson.

Install: Blogger → Theme → the arrow next to Customize → Backup (keep the
old one), then Edit HTML, replace everything with `theme.xml` of the built
pack, Save. Blogger then fills in its default markup of the widgets
(Header, Blog posts); the stylesheet styles that markup.

Status: well-formed XML, no leftover placeholders; not yet installed on the
blog. Blogger can refuse a theme on save: its message names the line.

The favicon is Blogger's own setting (Layout → Favicon): upload
`favicon-32.png` or `icon-192.png` of the pack.
