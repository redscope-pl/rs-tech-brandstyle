# Sphinx starter (Read the Docs)

Sphinx with the Furo theme in the RedScope style: colours from
`_static/brand/css/tokens.css`, the logo light and dark, the favicon, the
terminal-like system font.

Status: builds (`task check` of rs-tech-brandstyle); not yet seen on Read
the Docs.

When the docs live in a subfolder of a project, move `.readthedocs.yaml` to
the project's root and point `sphinx.configuration` and the requirements
path to the folder.
