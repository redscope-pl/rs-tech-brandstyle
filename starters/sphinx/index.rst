RedScope Technologies
=====================

A documentation project in the RedScope style. Replace this page with the
project's own; keep ``conf.py`` and ``_static/brand/``.

Getting started
---------------

.. code-block:: sh

   pip install -r requirements.txt
   sphinx-build -b html . _build/html

On Read the Docs, ``.readthedocs.yaml`` builds the same.

.. note::

   The theme follows the reader's light or dark scheme; the toggle in the
   corner switches it.
