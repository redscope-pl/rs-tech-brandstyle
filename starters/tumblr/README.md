# Tumblr theme

For `redscope.tumblr.com`, a blog of images: posts as a grid of cards,
one column on a post's own page, light and dark from the visitor's scheme,
the eye in the header (inline, nothing to host).

Install: Tumblr → the blog → Edit appearance → Edit theme → Edit HTML,
replace everything with `theme.html` of the built pack, Update preview,
Save. Keep the old theme's HTML somewhere first.

Status: checked for leftover placeholders and Tumblr's blocks; not yet
installed on the blog.

The favicon is the blog's avatar (`{Favicon}`): set the avatar to
`icon-512.png` of the pack to get the eye there too.
